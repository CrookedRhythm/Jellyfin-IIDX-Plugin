beatmania IIDX

Songs are listed from the game's music database and rendered from the original game files when you press play. Renders are kept for a while and then removed again; the game data is never modified.

Game data

The game's contents folder (the one holding data and optionally data_mods), as the Jellyfin server sees it. In Docker this is the path inside the container.
Leave empty to use the newest music_data.bin in data/info/0 or data/info/1.

Library

Holds song metadata, thumbnails, small placeholder files and the temporary renders. Empty uses <jellyfin data>/iidx/library.
Lets you sort the library by difficulty (sort by community rating).

Playback cache

Rendering
